# Number Guessing Game

A simple Node.js game where the program generates a random number between 1 and 100, and the player tries to guess it.

## How to play

1. Open a terminal in this folder.
2. Run:
   ```bash
   npm start
   ```
3. Enter your guess.
4. The game will tell you whether your guess is too high or too low.
5. Keep guessing until you find the correct number.
6. The program prints the total number of attempts when you win.

## Example

```bash
Welcome to the Number Guessing Game!
Guess a number between 1 and 100.
Enter your guess: 50
Too low! Try again.
Enter your guess: 75
Too high! Try again.
Enter your guess: 63
Congratulations! You guessed the number in 3 attempts.
```
